# 固定证据模型对比与来源绑定候选（2026-10-31）

## 决策与设计

冻结生成规则，不应用上一轮扩充“明示/未知/建议”的候选。用户明确禁止围绕失败案例任意堆叠提示词，已写入AGENTS.md。新增tests/helpers/history_generation_comparison.py，复用014—017现有observation.json最后一次正常工具循环请求；其中已含真实成功回读原文。两模型逐题获得完全相同消息，通过request_sha256核对；不追加提示、不绑定工具、不执行检索、状态写入或确认。保留既有系统上下文和历史工具交互，因此不是最小上下文消融或完整Agent链路评测。

每模型每题1次，共8次。standard=qwen3.7-plus，enhanced=qwen3.8-max，temperature=0.2，沿用调用入口timeout=180与外层retry_attempts=3，实验不加第二层重试。案例顺序固定，每题交替先后模型，非统计显著性实验。原文和提问在调用前于聊天完整展示，保存在输出cases中；review标签不发送给模型。

## 下一步方案及边界

两个业务文件共7个局部：读取工具增加citation_ref并替换工具描述；交互引用提示换成简短引用契约；出口函数支持短标记展开且兼容完整引用；每轮新建映射；最终出口传入映射；真实成功回读时登记映射。无新导入、模型调用、配置、数据库或快照变更。实际展开后的长引用进入展示/存档，短编号仅本轮有效，不能作为永久来源编号。未知标记只标识失败，不根据编号自动读取。缓存复用沿用首次成功登记。

此改动减轻复制负担，不解决解释支持性；未读取、陌生来源、缺括号均不得猜测补齐。主流程保持用户手动应用；完整前后局部放在聊天，不以临时验证脚本代替指导。语义支持性的独立离线核验是后续实验，不在本轮直接接入在线裁判或重写循环。
